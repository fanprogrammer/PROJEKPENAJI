# PENAJI (PENampungan Aspirasi HMJTI) - Redesain

Buka `index.html` di browser. Struktur: `index.html`, `css/style.css` (panel admin, modal, form, CTA, footer), `css/penaji.css` (tampilan publik baru), `js/app.js`, `assets/`.

- Tambah foto galeri: tambah satu objek ke array `GALERI` di `js/app.js`.
- Data aspirasi tersimpan di `localStorage` browser (simulasi, belum ada basis data). Status yang diubah di panel admin langsung tampil di bagian Progres Aspirasi.
- Login pengurus (demo): `admin@hmjti` / `hmjti2026`.
